Lance Lascari created the original Mathcad PLL worksheet (1999-2002) as
personal work, and manually translated the core analysis to GNU Octave, with
MATLAB compatibility as a secondary goal. Beginning in 2026, GitHub Copilot
added tooling around that core under Lance's direction and review, including
the configurator, runner, viewer, transient analysis, phase-noise profile
format, datasheet-extraction example, demonstration and tests. Files written
this way carry a "Generated by GitHub Copilot under Lance Lascari's direction"
header. Copilot is an AI tool, not a project maintainer or copyright holder.
